# SAM 객체 마스크 학습 및 자동 라벨링

## 1. SAM Fine-tuning

1. 저장된 에피소드를 선택하고 `Sample count`에 원하는 개수를 입력한 뒤 `Sample frames`를 누릅니다.
   기본 개수는 없으며 에피소드의 전체 프레임 수 이하로 지정합니다. 입력한 수만큼 추출합니다.
2. 각 프레임에서 객체마다 포인트로 마스크를 만들고 이름을 붙인 뒤 `Save` 합니다.
3. `Training scope`에서 같은 맵의 라벨링 완료 에피소드 전체 또는 현재 에피소드만 선택합니다. `Training labels`에서 합산된 라벨과 인스턴스 수를 확인하고 `Model name`을 입력한 뒤 `Train SAM`을 누릅니다.
   이름은 최대 80자이며 같은 맵에서 중복되지 않아야 합니다. 이름은 학습 진행 상태와 모델 선택 목록에 표시됩니다.
   `model.json`의 `model_name`에 저장하고 기존 내부 ID/폴더 및 마스크 참조는 유지합니다.
   이름이 없는 이전 모델은 맵과 생성 시각으로 표시합니다.

`Train SAM`은 같은 맵의 저장된 에피소드에서 **샘플 프레임마다 승인된 마스크가 하나 이상 있고 미검수 draft가 없는 에피소드**를 합쳐 학습합니다.
미완성 에피소드는 학습 대상에서 제외되며, 선택한 에피소드만 학습하는 옵션도 있습니다. 라벨 하나를 선택하는 필터는 없습니다.
샘플링한 프레임 밖의 마스크와 자동 생성 draft는 학습에 사용하지 않습니다.
학습 프레임 안의 미표기 영역은 background로 취급하므로, 보이는 대상 객체를 빠짐없이 라벨링해야 합니다.
서로 다른 클래스의 마스크가 겹치는 픽셀은 클래스 학습에서 제외합니다.

### 모델 구성

- SAM 2.1 Tiny 이미지 인코더와 프롬프트 인코더는 고정합니다.
- 마스크 디코더는 모든 인스턴스의 윤곽을 함께 학습합니다.
- SAM 이미지 특징 위의 클래스 헤드는 객체 라벨과 background를 학습합니다.
- 단일 모델 폴더에 `decoder.pt`, `classes.pt`, `model.json`을 저장합니다.
- `model.json`은 `object_labels`, `label_counts`, 프레임 수, 개별 학습 마스크 정보를 기록합니다.

기본 학습은 1,000 steps이며, 합산한 에피소드 전체에서 2–4,096개 인스턴스/최대 1,024개 프레임을 처리합니다.
이는 기본 SAM에 추가한 클래스 학습 모듈입니다. 기본 SAM 디코더만 학습하면 클래스 구분 기능이 생기는 것은 아닙니다.

## 2. Auto Labeling

1. 전체 라벨로 학습한 모델과 대상 에피소드를 선택합니다.
2. `Generate masks`는 모델이 학습한 모든 클래스를 한 번에 생성합니다.
   모델의 `training_samples`에 기록된 학습 프레임은 전체를 제외합니다. 재시도 시에도 제외하며 해당 프레임의 기존 라벨은 변경하지 않습니다.
   진행률의 전체 수는 학습 프레임을 제외한 실제 생성 대상 수입니다.
3. `Review masks`에서 한 프레임의 모든 클래스 마스크를 함께 확인합니다.
4. 잘못된 인스턴스는 선택해 수정하거나 ×로 제외하고 `Save review`를 한 번 누릅니다.
   남은 초안은 함께 승인되고 제외한 항목은 rejected로 저장된 뒤 다음 프레임으로 넘어갑니다.
   모든 마스크를 제외해도 해당 프레임은 검수 완료로 표시합니다. 저장 전에는 변경이 반영되지 않습니다.

추론은 `SAM 이미지 특징 → 학습한 클래스 헤드 → 객체별 SAM 마스크 → 중복 제거` 순서입니다.
외부 텍스트 탐지기나 고정된 person 프롬프트는 사용하지 않습니다.
각 인스턴스의 이름은 모델 출력에서 오며, 학습하지 않은 이름의 출력은 저장하지 않습니다.
모든 프레임에 모든 라벨을 강제로 붙이지 않고, 실제로 인식된 클래스만 생성합니다.

예: `person / dish / empty dish`로 학습하면 사람과 접시를 함께 찾고 접시는 학습한 상태에 따라 구분합니다.
동일 클래스 객체도 서로 다른 마스크/ID로 저장합니다. 자동 결과는 draft이며 검수 전 학습에서 제외됩니다.
기존 저장된 클래스는 보존하면서 누락된 클래스만 추가합니다. person이 있다고 dish 생성을 건너뛰지 않습니다.
프레임별 파일은 한 번 읽고 모든 클래스 결과를 한 번에 저장합니다.

### 호환성과 한계

이전의 `point_prompt_instances_v1` 모델은 클래스 학습 정보가 없으므로 새 자동 생성에는 사용할 수 없습니다.
기존 수동 마스크로 다시 Train SAM을 실행하면 됩니다. 이전 모델 파일과 수동 어노테이션은 유지됩니다.
적은 샘플은 같은 장면을 외울 수 있으며, 새 환경이나 음식 유무 구분의 정확도는 별도 검증이 필요합니다.
부정확한 라벨도 그대로 학습하므로 잘못된 정답은 먼저 고쳐야 합니다.

## 저장과 UI

- 데이터: `dataset/reasoning/<map>/raw_episode_####/samples.jsonl` 및 `masks/`.
- 여러 객체를 만든 뒤 Save 한 번으로 저장하며, 수동 Save 후 다음 샘플 프레임으로 넘어갑니다.
- Ctrl+휠로 줌, 드래그로 확대 이미지 이동, Expand view로 전체 화면을 사용할 수 있습니다.
- 진행률은 실제 training step 또는 처리한 frame 수입니다. 상태 조회는 데이터 저장 잠금과 분리됩니다.
- 모델은 추론 동안 메모리에 유지되며 수동 포인트 마스킹에는 기본 SAM 디코더를 복원합니다.

SAM 학습은 이미지 특징을 임시 디스크 캐시에 저장하고 현재 프레임만 메모리로 읽습니다. 정상 종료 또는 예외 종료 시 캐시는 정리됩니다.

자동 라벨 생성은 후보 클래스 신뢰도 ≥ 0.80, SAM 마스크 품질 점수 ≥ 0.80,
마스크 내부 평균 클래스 신뢰도 ≥ 0.80을 각각 요구합니다.
이 점수는 실제 정답률이 아닙니다. 중복 제거 IoU 기준은 0.5 그대로입니다.
설정 변경은 다음 자동 생성부터 적용되며 기존 저장 마스크는 변경하지 않습니다.
